# G1 readable Kernel graph notation

G1 is the first readable projection over canonical Kernel entities. It exists
to author the Kernel compiler and meta-schema without hexadecimal byte streams.
G1 is not canonical storage and is not intended to become a mandatory user
syntax.

Source is ASCII whitespace-separated tokens. `#` begins a comment through LF.
Directives are two bytes so the portable reader remains small. Unsigned decimal
integers are canonical and fit in 64 bits. Identities are exactly 32 lowercase
hexadecimal digits.

## Envelope

```text
ve 1
mo 00000000000000000000000000000001
rv 00000000000000000000000000000002
pc 0
ec 1
```

`pc N` is followed by `N` parent revision identities. `ec N` is followed by
exactly `N` entities. Parents and entities must use strictly increasing identity
order. The independent Kernel validator enforces canonical ordering after G1
emits the envelope.

## Entity and fields

```text
en ENTITY-ID SCHEMA-ID SCHEMA-VERSION FIELD-COUNT
fi FIELD-ID VALUE
```

Fields must be strictly ordered. Counts remain explicit in G1-BP1 so recursive
values can be parsed without a separate allocation graph. A later projection
derives counts while preserving the same canonical entities.

## Values

```text
un                         unit
fa                         false
tr                         true
uu UNSIGNED                unsigned integer
zz ZIGZAG-UNSIGNED         signed integer's canonical ZigZag payload
by LOWERCASE-HEX           bytes (an empty token is represented by `by -`)
rf IDENTITY                entity reference
li COUNT VALUE...          ordered list
rc COUNT (fi ID VALUE)...  record with sorted field identities
ho IDENTITY                unresolved hole
```

G1 deliberately exposes wire-neutral semantic primitives. Strings, maps, sets,
integer widths, sums, objects, effects, mechanics, and target concepts are
module schemas rather than additional G1 value forms.

## Compilation contract

```text
g1-compiler.k0 source.g1 output.seme
kernel-wire-validator.k0 output.seme
```

The compiler emits shortest-form integers and exact Kernel wire v1 framing.
Unknown directives, malformed identities/bytes, numeric overflow, count
mismatches, and trailing input reject with status 65. The independent Kernel
validator then rejects duplicate or unordered identities, dangling references,
invalid reserved meta-schema relationships, and any noncanonical envelope.
Successful G1 compilation is the complete two-command pipeline above, not the
emitter alone.
