# Project Contract v9

Project v9 (`...e000@...e00b`, parent `...e00a`) adds
`ResourceProjectSnapshot` (`e024`). It binds one exact Project-v8
`FullConfiguredProjectSnapshot` to one Resource-v1 `ResourceManifest` with a
32-byte content revision.

The revision imports exact Resource v1, Package v4, Execution v36,
Configuration v3, Dependency v1, and Foundation v1 authorities. Earlier
Project contract bytes remain immutable.
