# Patch Module v1

`module.g1` is the checked readable construction projection of the Patch Module
v1 schema. `reference/go/cmd/patch-module` reproduces it as a differential
fixture generator; `module.seme` remains canonical authority.

The executable workspace corpus is generated by
`reference/go/cmd/patch-fixture`. Every workspace contains the Patch and Rename
declarations, patch author, patch and operation instances, target declaration,
and target entity in one Kernel-valid envelope. Its valid, stale-revision,
failed-precondition, and duplicate-write variants all pass Foundation semantic
validation before Patch behavior is evaluated.

`apply-candidate.seme` is the authoritative isolated candidate stage. It
validates the base revision, resolves every operation, evaluates all
preconditions against the unchanged base, rejects duplicate writes, and only
then constructs a separate candidate. The candidate deliberately carries an
all-zero revision placeholder and cannot be published until the canonical
digest and stamp stages complete.

Reproduce and validate the graph:

```sh
bootstrap/seme-k0-linux-amd64 compiler/g1-compiler.k0 \
  modules/patch/v1/module.g1 /tmp/patch-v1.seme
cmp modules/patch/v1/module.seme /tmp/patch-v1.seme
bootstrap/seme-k0-linux-amd64 compiler/kernel-wire-validator-located.k0 \
  /tmp/patch-v1.seme
```

The repository gate runs this reproduction plus the differential oracle suite:

```sh
./scripts/check-semantic-modules.sh
```
