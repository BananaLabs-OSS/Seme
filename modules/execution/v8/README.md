# Core Execution v8

This module adds provider-neutral ordered `Block` and `Return` semantics to the
frozen v7 expression vocabulary. The checked `module.g1` construction
projection and compiled `module.seme` artifact are generated by
`reference/go/cmd/execution-module-v8` and validated by the Kernel and Semantic
Foundation validators.

No source-language grammar or application model is part of this module.
