# JavaScript UPB-01 evidence

Status: claimed 2026-09-11 by `scripts/check-javascript-upb-01.sh`.

The cumulative gate proves all seven evidence classes for a bounded ordinary
ES-module project. Independent files execute natively through pinned Node,
lift through the JavaScript provider, and agree with canonical, standalone
Wasm, and pinned Pulp observations. The provider-produced Execution artifact
binds directly to neutral Project v1 and a deterministic Project-v2 source
inventory; no Go source parser participates.

Tracked JavaScript is projected from canonical meaning while ignored,
generated, vendored, and opaque units retain exact bytes from a verified
digest-addressed bundle. The projected native project passes Node syntax and
behavior checks and re-lifts to byte-identical Execution and Project authority.
Repeated inventory, assembly, and emission agree. Unsupported semantics,
unsafe paths, symlinks, malformed types, and existing destinations reject
without partial publication.

This claim is deliberately bounded to one package containing multiple ES
modules. UPB-02 owns multiple package/module graph semantics. General npm
resolution, Node runtime compatibility, and arbitrary JavaScript remain outside
this cell.
