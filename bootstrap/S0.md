# Seme S0 bootstrap source notation

S0 is the first readable source notation compiled by a portable K0 program. It
exists to author the self-hosting kernel/compiler without raw bytes. It is not a
mandatory user syntax and does not define presentation for the eventual Seme
platform.

Source is ASCII whitespace-separated two-letter directives with unsigned
decimal operands. `#` begins a comment through LF. Header and function metadata
remain explicit in S0-BP1 so the first compiler does not need allocation or a
layout graph.

## Structure

```text
ve 3                    # K0 image version
cp 7                    # capability mask
fc 1                    # function count
fn 0 2 4 7              # parameters, locals, instructions, code bytes
cu 20                   # const.u 20
cu 22
ad
re
en 0                    # entry function
```

## Directives

```text
ve version              cp capabilities       fc function-count
fn params locals instructions code-bytes       en entry-index

re return               cu constant            lg local.get
ls local.set            dr drop                du dup
ad add                  su sub                 mu multiply
di divide               rm remainder           an bit-and
or bit-or               xo bit-xor             sl shift-left
sr shift-right          eq equal               lt less-than
ju target witness       bf target witness      ca call
bl bytes.len            bg bytes.get           bn buffer.new
bp buffer.push          ac arguments.count     ag arguments.get
fr fs.read              fw fs.write
```

Branch targets are semantic instruction indices; witnesses are derived byte
offsets as in K0. A later source profile replaces explicit counts, sizes, and
witnesses with names and deterministic layout. S0-BP1 is kept deliberately
small so its compiler can be audited and self-reproduced first.
