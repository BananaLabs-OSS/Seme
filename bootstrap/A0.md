# Seme A0 v1

A0 is the second construction notation. It adds canonical unsigned integer
encoding to Hex0 so later structured images can be written without calculating
LEB128 bytes by hand. It is deliberately not Seme and has no names, types,
functions, labels, or compiler policy.

## Grammar

Input is ASCII whitespace-separated directives:

```text
bHH       emit one byte; HH is exactly two hexadecimal digits
uDECIMAL  emit one unsigned 64-bit integer as canonical ULEB128
```

`#` begins a comment through LF or end of input. A directive must be followed by
whitespace, a comment, or end of input. Decimal values with overflow and
malformed directives are rejected.

## Invocation

```text
seme-a0-linux-amd64 INPUT.a0 OUTPUT
```

Exit statuses match Hex0: `0` success, `64` invalid invocation, `65` invalid
A0, and `74` operating-system I/O failure. Outputs are created with mode `0755`.

## Reproduction gate

The frozen Hex0 seed constructs the A0 executable from `a0-linux-amd64.hex`.
The resulting A0 executable then assembles `a0-linux-amd64.a0` into a
byte-identical copy of itself.
