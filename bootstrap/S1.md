# Seme S1 symbolic bootstrap notation

S1 is the final bootstrap-only source notation before canonical Kernel entities.
It preserves K0's small instruction vocabulary while removing derived layout
data from human-authored source. It is not a user language or canonical Seme
storage.

## Lexical form

Source is ASCII whitespace-separated tokens. `#` begins a comment through LF.
Identifiers match `[a-z][a-z0-9._-]*` and are compared byte-for-byte. Unsigned
integers are decimal, must fit in 64 bits, and reject leading zeroes except for
the value `0`.

## Image structure

```text
ve 3
cp 7

fn encode 2 3             # name, parameters, locals
  lg 1
  # ...
  re
fe

fn main 0 14
  lb scan
  # ...
  bf done
  ju scan
  lb done
  cu 0
  re
fe

en main
```

Function count, instruction counts, code byte sizes, function indices, semantic
branch indices, and byte-position witnesses are absent from source. The S1
compiler derives all of them from the complete image.

Source may contain multiple `re` directives. They lower to jumps into one
generated final return epilogue because frozen K0 requires `return` to be the
last instruction of every function.

Labels are scoped to one function, occupy no instruction index, and must be
unique. Functions are indexed in declaration order and must have unique names.
Forward calls and forward branches are allowed. Exactly one entry declaration
is required and it must name a zero-parameter function.

## Directives

S1 retains compact bootstrap mnemonics so the portable reader stays small. They
are not intended to dictate a human projection above the kernel.

```text
ve VERSION                cp CAPABILITY-MASK
fn NAME PARAMS LOCALS     fe
lb NAME                   en FUNCTION

re                        cu N
lg N                      ls N
dr                        du
ad                        su
mu                        di
rm                        an
or                        xo
sl                        sr
eq                        lt
ju LABEL                  bf LABEL
ca FUNCTION
bl                        bg
bn                        bp
ac                        ag
fr                        fw
```

## Deterministic lowering

The compiler performs two logical passes:

1. Parse declarations, assign function indices, instruction indices, and label
   targets; reject duplicate or unresolved names and numeric overflow.
2. Compute shortest-form ULEB operands and byte offsets to a fixed point, then
   emit canonical K0-P2 headers and instructions.

K0 branch witnesses encode byte offsets whose own ULEB widths can affect later
offsets. Starting with width one and repeatedly recomputing all offsets is
deterministic and converges because widths only increase and are bounded by ten.

The checked S1 compiler must be constructed once by S0, then rewritten in S1.
Generation B and generation C must be byte-identical before S1 replaces S0 as
the bootstrap authoring floor.
