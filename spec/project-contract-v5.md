# Project Contract v5

Project Contract v5 pins Execution v35, Package v3, and Dependency v1. Its
`CompleteProjectGraphSnapshot` binds the Project v4 dependency graph to the
Package v3 complete package graph with a content-derived revision.

The binding adds no language-specific type model. Canonical Execution entities
remain the authority for declaration structure and behavior; Package owns them
and Project composes the authenticated graphs.
